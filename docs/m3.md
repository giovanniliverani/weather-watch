## What the rules are

A document is scored against the live events of its hazard class whose window overlaps its own and that a resolved place puts within twice the hazard's blocking radius, or that share its country, or whose own query fetched it. s = 0.45 spatial + 0.25 temporal + 0.3 text (no resolved place: 0.2 temporal + 0.8 text, text at least 0.6), +0.1 when the event's query fetched the document; at or above 0.75 attached, at or above 0.55 a candidate for the Review tab, below that nothing.

## How to tune

1. Edit the `attachment:` section of `identity.yaml` (weights, thresholds, windows) or `eww/data/lexicon.yaml` (terms and negative patterns).
2. Re-decide every pipeline row on a copy of the database: copy `data/eww.sqlite` to `data/copy.sqlite`, then `uv run eww --db data/copy.sqlite attach --rebuild`.
3. Re-run `uv run eww eval attachments --sample 100`, label, and `uv run eww eval attachments` for this report.
